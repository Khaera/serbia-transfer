# Визараны и трансферы по Сербии
## Демо
[Открыть сайт](https://khaera.github.io/serbia-transfer/)

Сайт создан для россиян с целью ознакомления с процедурой визарана из Сербии в Боснию и Герцеговину, поездок в IKEA за покупками и трансферы в/из аэропортов Белграда, Ниша или Кральево. Связь со мной через WhatsApp или Telegram.

Создан калькулятор, который рассчитывает последний день 30-дневного пребывания по дате въезда, показывает остаток дней и предупреждения. День въезда учитывается как первый.

Для создания сайта использовались: 
- HTML;
- CSS;
- Vanilla JavaScript.

Для локального запуска сайта необходимо:
1. Скачать репозиторий
2. Открыть index.html
3. Возможен запуск через расширение **LiveServer**
